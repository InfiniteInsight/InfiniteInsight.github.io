# CSR-Wizard

![](assets\images\CSR-Wizard.jpg)
_Creating Certificate Singing Requests is tedious and a pain._

Most people who need to do it don't know how. Who could blame them? It's not exactly riveting.

CSR-Wizard is an application I developed to help people create CSRs and to interact with the resulting private and public keys. 

CSR-Wizard also enables users to analyze certificates for deeper understanding with rich context that the OS does not provide and OpenSSL makes you really work for.

It is cross platform and will work on any Operating System.

It'll be released on Github once QA and pentesting is completed. The current UI is a minimal viable product representation and is not final.
