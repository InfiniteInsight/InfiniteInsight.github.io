# Aegis

Aegis is a code watermarking research and development project of mine. 

I am exploring the feasibility of watermarking code using a multi leveled approach to watermark code in a way that is transparent to the functionality of the code and invisible to people. 

This would be for intellectual property protection as well as tracing sources of leaks.

Cryptographically signed attestations are generated to present as evidence to demonstrate intentionality. These can be stored in vaults or on the blockchain.

Since this is still in the research and development phases I will not share much more about it until I have more certainty.
